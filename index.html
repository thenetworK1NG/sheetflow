The window.sf API

40+ methods. Zero dependencies.

Every SDK module is a plain IIFE — no build step, no framework. Tools call registerTool() and get full access to the workspace through a single namespace.

Build and share

Ship a tool in a single .sf file.

Every tool is a self-contained .sf file. It calls registerTool(), gets access to the full window.sf SDK, and injects its own UI into the workspace. No core changes required.

.sf tool files One-click install Full SDK access
Read the SDK docs → Try it live ↗ Download demo tool ↓
my-tool.sf 
registerTool({
  id: "row-highlighter",
  name: "Row Highlighter",
  icon: "🎨",

  activate() {
    // Add a button to the topbar
    sf.addTopbarButton({
      id: "hl-toggle",
      label: "🎨 Highlight",
      onClick: () => toggleHighlights()
    });

    // React to data changes
    sf.on("data:changed", () => {
      refreshHighlights();
    });

    // Register a keyboard shortcut
    sf.registerShortcut({
      key: "h", ctrl: true,
      label: "Toggle highlights",
      handler: () => toggleHighlights()
    });
  },

  deactivate() {
    sf.off("data:changed");
  }
});
